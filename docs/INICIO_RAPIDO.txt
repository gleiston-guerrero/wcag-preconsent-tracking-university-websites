INICIO RAPIDO — ejecutar el script en Windows
=============================================

Si prefiere no leer el manual completo, esto es lo minimo.


PASO 1. Crear la carpeta y copiar los archivos
----------------------------------------------
Cree la carpeta   C:\auditoria
Copie dentro:     INSTALAR.bat
                  ejecutar.bat
                  auditar_multipunto.js
                  analizar_multipunto.py
                  universidades.json     <-- su lista de los 126 sitios

NO use carpetas dentro de OneDrive, Escritorio ni Documentos.


PASO 2. Instalar (una sola vez)
-------------------------------
Doble clic en   INSTALAR.bat

Instala Node.js, Python, Playwright, axe-core, el navegador Chromium,
scipy y numpy, e impide que el equipo se suspenda. Al final ofrece una
prueba con 5 sitios.

Si le pide cerrar y volver a abrir la ventana, hagalo: es normal, ocurre
una o dos veces mientras instala Node.js y Python.


PASO 3. Medir
-------------
Doble clic en   ejecutar.bat

Le pregunta dos cosas:
  1. El punto de observacion (EC, EU o US).
  2. CUANTAS pasadas nuevas quiere hacer.

El propio programa mira que pasadas ya existen para ese punto y numera las
nuevas solo. Si para EC ya existe la pasada 3 y usted escribe 2, ejecutara
la 1 y la 2 encadenadas, sin volver a preguntarle nada.

Como todas las pasadas de un mismo punto usan la misma VPN, se encadenan
solas con una pausa de 60 segundos entre una y otra. No hay que estar
delante.

Antes de cada ejecucion, ponga la VPN como corresponda:

    EC  ->  VPN APAGADA (su conexion normal en Ecuador)
    EU  ->  VPN conectada a un pais de la UNION EUROPEA
            (Alemania si la tiene; si no, Paises Bajos, Francia o Espana)
    US  ->  VPN conectada a ESTADOS UNIDOS

Sirve cualquier VPN que cumpla tres cosas:
    1. Que sea aplicacion de escritorio, no extension de Chrome.
    2. Que deje elegir el pais a mano.
    3. Que su bloqueador de rastreadores se pueda APAGAR.

Y desactive ese bloqueador antes de medir:
    McAfee  -> revise que no haya proteccion web activa sobre el trafico
    Mullvad -> Configuracion > VPN > Bloqueadores de contenido DNS: TODO desmarcado
    Proton  -> NetShield: APAGADO

SI USA McAFEE (u otra VPN incluida con un antivirus):
    - Pongala en modo manual o siempre activa, NO en "solo en wifi no segura".
    - Fije la ubicacion virtual al pais que toca, no en "automatica".
    - No tiene cortafuegos de emergencia, asi que el script comprueba el pais
      cada 25 sitios y al terminar; si la VPN se cae, avisa y aborta la pasada.

Lo ideal son tres pasadas por punto, nueve ejecuciones en total. Cambie de
punto en cada sesion para que el orden no coincida siempre con la hora:

    Sesion 1:   EC (1 pasada)  ->  EU (1 pasada)  ->  US (1 pasada)
    Sesion 2:   EU (1 pasada)  ->  US (1 pasada)  ->  EC (1 pasada)
    Sesion 3:   US (1 pasada)  ->  EC (1 pasada)  ->  EU (1 pasada)

Si prefiere hacerlo del tiron, puede pedir 3 pasadas de un punto y dejarlo
corriendo dos horas, pero rotar entre dias es metodologicamente mejor.

Cada ejecucion dura entre 30 y 50 minutos. No use el equipo mientras corre.


PASO 4. Analizar
----------------
Abra PowerShell, y escriba:

    cd C:\auditoria
    python analizar_multipunto.py

Para el resultado clave del articulo (solo universidades europeas):

    python analizar_multipunto.py --paises DE,FR,ES,NL,BE,SE,CH,GB --salida analisis_europa.txt


SI PREFIERE TECLEAR EN VEZ DE HACER DOBLE CLIC
-----------------------------------------------
Instalacion, en PowerShell COMO ADMINISTRADOR:

    Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
    winget install --id OpenJS.NodeJS.LTS -e
    winget install --id Python.Python.3.12 -e
    (cierre y reabra PowerShell)
    cd C:\auditoria
    npm init -y
    npm install playwright axe-core
    npx playwright install chromium
    python -m pip install scipy numpy
    powercfg /change standby-timeout-ac 0

Prueba con 5 sitios:

    node auditar_multipunto.js --vantage=EC --run=0 --limit=5

Las mediciones, una orden por pasada. El numero de --run lo elige usted y
NO debe repetirse dentro del mismo punto, o sobrescribiria la anterior:

    node auditar_multipunto.js --vantage=EC --run=1
    node auditar_multipunto.js --vantage=EC --run=2
    node auditar_multipunto.js --vantage=EU --run=1
    ... y asi con los tres puntos

Con ejecutar.bat no hay que preocuparse por esto: numera solo.


SI ALGO FALLA
-------------
"node no se reconoce"
    Cierre y reabra la ventana. Si sigue, reinicie el equipo.

"la ejecucion de scripts esta deshabilitada"
    PowerShell como administrador:
    Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

"Executable doesn't exist at ..."
    cd C:\auditoria
    npx playwright install chromium

"Cannot find module 'playwright'"
    cd C:\auditoria
    npm install playwright axe-core

El programa avisa de que el pais no coincide
    La VPN no esta conectada o esta en otro pais. Ctrl+C, corrija y repita.

Se corto a mitad
    Vuelva a teclear la MISMA orden: reanuda donde quedo.


ANTES DE DAR POR BUENOS LOS RESULTADOS
--------------------------------------
Mire la SECCION 1b del informe de analisis, la de calibracion. Compara las
cookies TOTALES depositadas en cada punto. Si un punto aparece marcado como
SOSPECHOSO, ese nodo de VPN estaba perdiendo contenido de terceros y sus
cifras de rastreo NO son comparables: repita ese punto desde otro servidor
del mismo pais antes de usar nada.

Es un fallo real que ya ocurrio una vez: un nodo aleman deposito un 36 %
menos cookies que los otros dos puntos, y eso producia una diferencia que
parecia segmentacion geografica y no lo era.


LO UNICO QUE NO PUEDE FALLAR
----------------------------
1. El bloqueador de rastreadores de la VPN tiene que estar APAGADO.
   Si queda encendido, la VPN bloquea Google Analytics y el pixel de Meta,
   usted registra cero rastreo en todas partes, y el estudio se arruina.

2. El punto EC se mide SIN VPN. Es su conexion real en Ecuador.
